\section{Modifications to the diffusion model}

\subsection{Conditional Diffusion Models} \label{sec:conditioning}

The "standard" sampling strategy (see \autoref{sec:sampling}) allows the model to draw a sample from the latent space representation it was trained to create. While this is useful for unconditional data generation, it does not help much on the task of \gls{downscaling}. For the \gls{downscaling} task, it is important to have a methods of relating the generated sample to the low-resolution input in sampling time. In other words, it is undesirable to re-train the model for each input condition. It would be much more desirable to request the \gls{downscaling} for a specific condition after the model is trained. This both allows us to train vastly fewer models, and it allows for training on multiple data-points.

The method, on which we this thesis will be based, was developed by Saharia, et. al. \cite{sr-diffusion} in 2021 (among the authors is also Ho, Jonathan, who authored the original DDPM-paper referenced earlier). The paper explains the process of \gls{downscaling} (in the paper called super-resolution) by iterative refinement on a conditional diffusion model. For now, let's focus on the condition diffusion-part. 

The approach is simple. During training the model is shown a high-resolution target image along with a high-resolution conditional image. The high-resolution conditional is generated using a bilinear/conservative (depending on the variable) interpolation of the low-resolution image, to the target scale \cite{sr-diffusion}. The target and condition are then concatenated on the channel dimension to create the input:
\begin{equation}
    X_t = \{ y, C \}
\end{equation}
Where $y$ is the target image, and $C$ is the conditional image.

In sampling, this method works in a very similar way, only here there is no target. Instead the condition is concatenated to a noise sample, which fits the dimensionality of the desired target. This allows the network to have some information of the initial resolution of the image.

The method comes with two caveats:
\begin{enumerate}
    \item The backbone model needs to be designed specifically for this purpose, as the number of channels for the input changes. It therefore destroys any hope of using a standard pre-trained diffusion model.
    \item We have to make the assumption that a model can, within reason, interpolate between the conditional data and the target data. In most cases this is a fair assumption, but in some cases the condition data originates from a different data set than the target data (foreshadowing...).
\end{enumerate}

\subsection{Residual Target Learning}

A common issue in machine learning is predicting the extreme. Logically, extremes do not often occur in data, and are therefore difficult to correctly predict for most machine learning models. Often, the predictions lie close to the overall mean of the target distribution. This is especially an issue in climate modelling as certain regions can exhibit locally extreme events. 

Another issue is, that due to the nature of the mean squared error loss function, it is much easier to correctly model normally distributed data rather than odd, non-parametric distributions.

To combat both issues, I propose to use residual target learning, similar to what is described in \cite{tomasi}. As the term "residual" is used in abundance throughout machine learning and climate science, let's first define residual target learning, then argue for why it solves the above issues.

In this case residual target learning describes a \gls{downscaling} method in which the model, instead of directly predicting the values of the downscaled target, predicts the difference between the low-resolution and high-resolution data in each grid point. Formally, it could be described as:
\begin{equation} \label{eq:residuals}
    r_{t,c,i,j} = H_{t,c,i,j} - L_{t,c,i,j}
\end{equation}
Where $r$ is the residual between the high-resolution, $H$, and regridded (see \autoref{sec:regridding}) low-resolution, $L$, images. The dimensions are $(t,c,i,j)=$ time, channels, and two spatial dimensions.

With this method, the model can instead predict the exact change it takes to pass from the known low-resolution data, to the high-resolution data. Instead of the model focussing on learning that e.g. the north is colder than the south, while also learning the anomalies between the two data sets, it can now focus its processing power on learning anomalies. This effectively solves the first of the above issues, as the extreme events are now stored in the low-resolution data.

Residuals have an additional, useful property, namely that for randomly occurring errors, they are normally distributed. The error between the high- and low-resolution data is not quite random, there are some biases, as we can see in \autoref{fig:tas-11-timeseries} and \autoref{fig:pr-11-timeseries}. However, even with a clear bias, the distribution is much closer to normal than that of the absolute values.

It is clear that the absolute values in the left and middle columns are further from the near-normal distribution in the right column. \subsection{Gamma-correction}

In image processing, one might run into the issue, that the dark parts of an image are too dark, perhaps it hides features you wish to show or it results in an undesirable tone of the image. The issue often arises as the human is more sensitive to darker tones than the lighter ones (in line with Stevens's power law). In other, more statistical terms, the human eye perceives light with a heavy right-tailed distribution. 

To correct for such behaviour, we can "correct" the image using gamma-correction \cite{gamma-correction}. Gamma-correction works by applying a power to the image intensities:
\begin{equation}
    s = cr^{\gamma}
\end{equation}
Where $r$ is the original image, $c$ and $\gamma$ are selected hyper-parameters, and $s$ is the corrected image.
